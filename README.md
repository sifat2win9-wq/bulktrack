# BULKTRACK

Personal muscle-building, nutrition and gym tracker. Single-page app, no build step, data stored in your browser (localStorage).

## Run locally
Open `index.html` in a browser.

## Free hosting with GitHub Pages
1. Create a new repository on github.com and upload all files in this folder.
2. Repo **Settings > Pages > Build and deployment**: Source = "Deploy from a branch", Branch = `main`, folder = `/ (root)`. Save.
3. After a minute your app is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Install on your phone
- Android (Chrome): menu > Install app / Add to Home screen.
- iPhone (Safari): Share > Add to Home Screen.

## Notes
- Data is per device/browser. Use Settings > Export to back up.
- Calorie and weight targets are estimates, not medical advice.
